The contract

Four rules the generator never breaks.

The blueprint contract isn't documentation — it's the pipeline. Validation runs fatal checks for placeholder and format violations before a draft can ship.

01

Start from one seed

A single spark in, nothing else. No parallel inputs, no drift between assets.

02

Generate in dependency order

Each asset is compiled only after whatever it depends on exists.

03

Keep formats module-specific

The a1111 layer is an image prompt; the sheet is a sheet. Nothing bleeds across.

04

Never leak downstream facts

The character sheet can't know its own intro scene. Context flows one way, always.

Surfaces

Primary

Quick start

Two commands from a checkout.

Node 20+ and pnpm 9+ — that's the whole prerequisite list.

browser workspace
pnpm install
pnpm dev:web # → http://localhost:5173
# drafts & keys persist client-side; the page talks
# straight to the provider you configure
docker web stack
pnpm docker:web
preview :3000 · dev server :3100
# for LAN access: pnpm dev:web:lan
