# A1111 Tag Prompt Layout

<a1111_generation_protocol>

<core_execution>
Output_Type = "Raw_Plaintext_ONLY"
Markdown_Bypass = TRUE -> STRICTLY_PROHIBITED: (Code_Fences, Headings, Bullet_Points, Conversational_Text)
Line_Count = EXACTLY_5
Line_Order = [1_person, 2_clothes, 3_location, 4_action, 5_anchor]
Syntax_Rules = [Comma_Separated, NO_Trailing_Commas, One_Tag_Per_Concept, Compact_Density_Over_Sentences]
</core_execution>

<tag_lexicon_mandate>
Allowed_Lexicon = REAL_DANBOORU_TAGS_ONLY
Banned_Formats = [Pseudo_Tags, Natural_Language, Sentences, Invented_Descriptors, Synonym_Piles, Full_Control_Template_Expansion]
Logic_Gate: IF (Tag == Redundant) -> OMIT_DUPLICATE (e.g., KEEP small_breasts, OMIT flat_chest)
Quality_Bias = [Warm_Bright_Lighting(Default_Unless_Dim_Tagged), High_Visibility_Details]
Verification_Rule: IF (Danbooru_API_post_count == 0) -> DISCARD_TAG(Dead_Tag)
</tag_lexicon_mandate>

<field_mapping>
Person_Matrix = [Subject_Count, Age_Descriptor, Role, Heritage/Species, Body_Type, Core_Visual_Read]
Clothes_Matrix = [Outfit_Silhouette, Fabrics/Materials, Color_Palette, Accessories]
Location_Matrix = [Environment_Type, Scene_Mood, Time/Weather/Lighting_Source]
Action_Matrix = [Pose/Framing, Facial_Expression, Hand/Body_Gesture, Prop_Interaction]
Anchor_Matrix = [Render_Style, Palette_Bias, Emotional_Tone, Camera_Feel/Texture, Scene_Category_Tags]
Anchor_Constraint = MUST_PLACE(Scene_Category_Tags -> VERY_END_OF_ANCHOR_LINE)
</field_mapping>

<dual_encoder_sync>
Target = SDXL_Architecture (ComfyUI/Illustrious)
Sync_Requirement = TRUE
Execution = MUST_DUPLICATE_STRINGS(person_encoder == anchor_encoder)
Constraint = "Both Person (227) and Anchor (231) nodes MUST receive the same text. All 5 lines form ONE continuous prompt. Copy 'person' line for the positive prompt, copy 'anchor' line for the second encoder input."
</dual_encoder_sync>

</a1111_generation_protocol>

---

## USAGE NOTE

The final output must be only the five tag lines. No commentary, headings, extra labels, or code fences. `person` and `anchor` lines (including all five lines' content) must be passed to both CLIP encoders in the SDXL dual-encoder setup.

---

## TAG VERIFICATION

Before using any tag, verify it's real via the Danbooru API:

```bash
curl -s "https://danbooru.donmai.us/tags.json?search[name]=TAGNAME&limit=1"
# post_count = 0 → dead tag, don't use it
```

**Canonical reference:** `creative/comfyui` skill → `references/danbooru-tag-reference.md` — 200+ mappings with post counts, pseudo-tag corrections, and two-character composition patterns.
