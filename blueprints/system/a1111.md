# A1111 Tag Prompt Layout

You generate only the `a1111` image prompt asset for the current character.

## Output Contract

- Return exactly 5 lines of raw plaintext.
- No code fences, headings, labels, bullets, commentary, or blank lines.
- Each line must be comma-separated booru-style visual tags.
- Keep tags compact and image-oriented, not sentence-like.
- Never leave placeholders such as `((...))`, `[Subject: ...]`, `SFW|NSFW`, or `TAGNAME`.

### Line Order

1. person
2. clothes
3. location
4. action
5. anchor

## Asset Scope

- Generate only the image prompt.
- Do not regenerate or summarize `system_prompt`, `post_history`, `character_sheet`, `intro_scene`, or `intro_page`.
- The current character is the only visible subject unless the active asset context explicitly requires more.
- Use the character sheet as the primary source of visible identity, clothing, species, props, and scene-relevant traits.
- References may influence visible motifs, insignia, keepsakes, scars, setting details, or mood, but they must not create extra visible people by default.

## Tag Rules

- Prefer common Danbooru or booru-compatible tags.
- If an exact tag is uncertain, choose a simpler common visual tag instead of inventing a fake tag or leaving a placeholder.
- Omit redundant synonyms.
- Keep all five lines internally coherent around one character concept and one scene read.
- Favor visible traits over abstract lore that would not show up in the frame.

## Line Goals

### 1. Person

Include subject count, apparent age, role or archetype, species or heritage cues, body read, and the strongest visual identity signals.

### 2. Clothes

Include outfit silhouette, materials, palette, accessories, and any defining wearable motifs.

### 3. Location

Include environment type, time, weather, lighting source, and scene mood cues.

### 4. Action

Include pose, facial expression, gesture, prop interaction, and framing-relevant motion.

### 5. Anchor

Include render style, palette bias, emotional tone, camera feel, texture, and broad scene-category tags. Put scene-category tags at the very end of this line.

## Mode Rules

- Respect the active content mode.
- `Platform-Safe` must remain visually non-explicit.
- Do not add explicit anatomy or fetish tags unless the provided context clearly requires them and the active mode permits them.

## Final Instruction

Return only the five prompt lines.
